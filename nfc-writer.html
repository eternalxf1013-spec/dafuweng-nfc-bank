1. 标签规格 — NTAG215

参数值
标签型号NXP NTAG215 (NTA215)
用户容量540 bytes（135 页 × 4 bytes，页 04h–88h）
UID 长度7 bytes（只读，硬件序列号）
页面大小4 bytes / page
NDEF 支持是（Capability Container 自动配置）

3. Payload 统一格式

所有卡片类型共用一条 pipe-delimited 文本，格式如下：

MONOPOLY|<type>|<key>|<name>|<id>
字段类型说明
MONOPOLY固定头魔数，用于识别本应用的标签（8 字节）
<type>枚举player · property · fee · spin · space
<key>字符串类型内唯一键：玩家 P+id / 地产 id / fee kind / spin kind / space key
<name>UTF-8人类可读名称（中文城市名 / 卡名）
<id>整数数字 ID（玩家/地产有值；费用/转盘/空间为 0）
