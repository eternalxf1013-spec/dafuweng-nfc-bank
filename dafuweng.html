📋 NFC 绑卡操作说明

三种 NFC 卡类型
💳 玩家卡 — 每位玩家一张，用于身份验证（转账/购地/建房等操作需刷卡确认）
🗺️ 地产卡 — 每块地产可绑一张，刷卡快速打开该地产面板
🏠 费用卡 — 房屋建造费卡 + 旅馆建造费卡，建房时刷卡授权

一、绑定玩家卡

方式 A — 添加玩家时直接绑：
1. 点击「+ 添加」打开添加玩家面板
2. 填好姓名和初始金额后，点击「绑定NFC卡」旁的「刷卡」按钮
3. 将 NFC 卡贴在手机背面（或点「模拟刷卡」选一张卡）
4. 卡号自动填入输入框，点击「创建」完成绑定

方式 B — 先创建玩家，稍后再绑（推荐）：
1. 点「创建」直接添加玩家（可不填卡号）
2. 玩家列表中点该玩家卡片右侧的「💳 绑卡」按钮
3. 刷一张 NFC 卡即完成绑定
4. 💡 也可以不手动绑：之后任何需要刷该玩家卡的操作（转账/购地/建房等）时，直接刷一张新卡，系统会自动绑定为该玩家的卡

方式 C — 在卡片管理中绑：
1. 进入「卡片管理」标签页
2. 在「玩家卡」区域找到对应玩家，点「绑卡」或「重绑」
3. 刷一张 NFC 卡即完成绑定

二、绑定地产卡

1. 进入「卡片管理」标签页
2. 在「地产卡」区域找到对应地块，点「绑卡」或「重绑」
3. 刷一张 NFC 卡，即与该地块绑定
4. 之后空闲时刷该卡 → 自动打开地块面板（无主则弹出购买确认）

三、绑定费用卡

1. 进入「卡片管理」标签页
2. 在「建造费用卡」区域，分别给「房屋建造费」和「旅馆建造费」绑卡
3. 点「绑卡」→ 刷一张 NFC 卡即可
4. 之后建造房屋/旅馆时，系统会提示刷对应费用卡授权

四、日常使用

空闲刷卡（非操作中）：
• 刷玩家卡 → 显示该玩家资产详情
• 刷未绑定地产的空白卡 → 提示去卡片管理绑定
• 刷已绑定的地产卡 → 打开该地产面板

操作中刷卡（有待确认步骤时）：
• 顶部横幅会提示当前需要刷哪种卡
• 刷错卡会拒绝并提示正确的卡类型
• 点「取消」可随时放弃当前操作
💡 模拟模式 / 真实 NFC 切换：点击顶部的「模拟模式 · 点此启动NFC」状态条（或银行页「启动NFC读卡」按钮）即可随时切换到真实 NFC；再点会提示已在运行。

📱 安卓 Chrome 注意：用文件管理器直接打开本地 HTML（content:// 地址）属于非安全环境，浏览器禁止 NFC，只能用模拟模式。想用真实 NFC 请用以下任一方式访问本页面：
• 手机装本地服务器 App（如 Simple HTTP Server），把 HTML 放进目录后用 Chrome 打开 http://localhost:端口（localhost 视为安全环境，NFC 可用）
• 把页面部署到任意 HTTPS 地址（如 GitHub Pages）再用 Chrome 打开

模拟模式下点「模拟刷卡」可从已绑定卡片中选择或生成随机新卡，功能与真实刷卡完全一致。
